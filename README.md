# Sea Level

## Overview

**Sea Level** is a Python data analysis project examining historical sea-level changes and using linear regression to model long-term trends.

The project uses historical CSIRO adjusted sea-level measurements to visualize changes over time and create projections through 2050.

## Objective

The goal of this project was to:

* Analyze historical sea-level measurements
* Identify the overall relationship between year and sea-level change
* Apply linear regression to estimate long-term trends
* Compare the historical trend with projected sea levels
* Visualize the results in a clear, interpretable format

## Tools & Technologies

* **Python**
* **Pandas**
* **NumPy**
* **Matplotlib**
* **Scikit-learn**
* Jupyter Notebook

## Analysis

The analysis uses the `Year` variable as the independent variable and `CSIRO Adjusted Sea Level` as the dependent variable.

I created a scatter plot of the historical observations and added regression lines to show projected sea-level trends.

Two projection ranges were examined:

* **1880–2050:** Long-term historical trend and future projection
* **2000–2050:** More recent trend used to examine the projected trajectory from the modern period

## Visualization

The final visualization combines the historical observations with regression-based projections to make the long-term trend easier to interpret.

The chart includes:

* Historical sea-level observations
* A regression trend from 1880–2050
* A regression trend from 2000–2050
* Labeled axes and a descriptive t
